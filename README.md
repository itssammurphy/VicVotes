# VicVotes

Ongoing data sceince project exploring voting patterns in Victorian state elections, beginning with my home district of Essendon.

## Essendon 2022

The first analysis examines first-preference results from 2022. Labor's Danny Pearson received 41.07% of first preferences, compared with 29.45% for the Liberal candidate and 15.15% for Greens. Following the distribution of preferences, Labor won with 62.45% of the two-candidate-preferred vote.
